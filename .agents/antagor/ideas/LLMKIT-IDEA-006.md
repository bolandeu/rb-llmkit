Из плана и спецификации v1, что осталось вне эпика E-003 (теперь это идеи, а не файлы).

1. Streaming: `llm ask --stream` и `generate(stream=True)` — шлюз уже отвечает потоком, llmkit собирает ответ целиком; нужен путь отдачи по частям.
2. Батч-API провайдеров (OpenAI Batch, Anthropic Batches) для пачек, где не важна скорость: вдвое дешевле.
3. `llm cost --export csv|json` и отчёт за период по дням.
4. Сентинел для `default`: сейчас `default=None` неотличим от «default не задан», вернуть осмысленный None нельзя.
5. Скилл агента (Claude Code и другие): вызов `llm ... --json` для массовой обработки дешёвыми моделями.
6. Прогресс и возобновление пачек: `ask_many` с чекпоинтом по `Task.id`, чтобы возобновление не зависело только от ответа шлюза.

Условие: эпик E-003 выпущен; каждая строка — отдельная задача со своей приёмкой.
