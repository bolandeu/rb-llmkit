## Problem

The response cache is a local SQLite file per worker. With several Windmill workers the same call misses on one and hits on another, answers differ at temperature>0, and repeat runs cost money (T446).

## Goal

Every worker that uses one LLMKIT_DATABASE_URL shares one cache: the same call gives the same answer, the second one is a free hit.

## Acceptance (Given–When–Then)

- Given two LlmKit instances on one database URL, When the first asks a call and the second asks the same call, Then the second is a cache hit with the first one's answer and cost 0.
- Given two instances asking the same uncached call at once, When both finish, Then one answer is stored and every later call returns that same answer (first write wins).
- Given a database without the cache table, When 'llm db upgrade' runs migration 0003, Then the table exists; 'llm db status' shows head 0003; usage rows stay untouched.
- Given a cache entry older than the TTL, When it is asked, Then it is a miss; expired rows are removed.
- Given no database URL, When a call is made, Then the cache works in the local default database as before, and an old cache.sqlite is ignored without an error.
- Given the cache database is unreachable, When a call is made, Then the call goes to the provider and a warning is given; it does not fail.

## Implementation decisions

- New table llmkit_cache (key primary key, model, created_at, response JSON), kind 'cache', migration 0003, mirrored in the table metadata.
- Cache storage uses the same database engine and URL as usage; the key function stays unchanged.
- set is insert-if-absent (ON CONFLICT DO NOTHING on PostgreSQL and SQLite); get is a primary-key read with the TTL check.
- llm config path / describe show the cache location as the database.

## Test seams

- LlmKit.ask with two instances on one database URL (SQLite file in unit tests, PostgreSQL in scripts/pg_test.sh)

## Out of scope

- Copying old cache.sqlite entries.
- Changing the cache key or temperature behaviour.
- A path-on-shared-volume workaround.
