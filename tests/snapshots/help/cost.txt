
 Usage: llm cost [OPTIONS]

 Показать расходы из журнала вызовов.

 Без `--by` печатается одна итоговая строка. На пустом журнале — пустая
 таблица и код выхода 0; 2 — неверный период.

 Example: llm cost --by tool --since 7d

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --by           <str>  Метки для группировки через запятую, например tool,niche.                  │
│ --since        <str>  Начало периода: 7d, 12h, 2w или ГГГГ-ММ-ДД.                                │
│ --until        <str>  Конец периода в том же формате.                                            │
│ --json                Машинный вывод: JSON-конверт в stdout.                                     │
│ --help                Show this message and exit.                                                │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
