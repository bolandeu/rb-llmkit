
 Usage: llm audio transcribe [OPTIONS] {file}

 Расшифровать речь из файла: текст, модель и цена из ответа шлюза.

 Коды выхода: 0 — готово, 2 — нет routing или файла, 3 — нет ключа шлюза,
 5 — шлюз недоступен или ответил ошибкой.

 Example: llm audio transcribe speech.mp3 -m openai/whisper-1 --json

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    file      <str>  Файл с речью. [required]                                                   │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ *  --model     -m      <str>  Модель шлюза строкой как в его настройке. [required]               │
│    --language          <str>  Язык речи кодом, например ru.                                      │
│    --routing           <str>  Routing v1: JSON или файл; иначе LLMKIT_ROUTING_FILE, иначе файл   │
│                               по умолчанию.                                                      │
│    --json                     Машинный вывод: JSON-конверт в stdout.                             │
│    --help                     Show this message and exit.                                        │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
