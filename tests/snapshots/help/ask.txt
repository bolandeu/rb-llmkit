
 Usage: llm ask [OPTIONS] [text]

 Задать вопрос модели и напечатать текстовый ответ.

 Цепочка моделей берётся из уровня конфига; упавшая модель уступает
 следующей. Вместо текста — шаблон: `--template` с `--vars` (как у
 `llm render`; в учёт расходов — имя и хэш шаблона, без значений). Коды
 выхода: 0 — ответ получен, 2 — неверные аргументы или нет переменной
 шаблона, 3 — нет ключа провайдера, 5 — все модели упали.

 Example: llm ask "Столица Франции?" --level cheap

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│   text      <str>  Текст запроса; без него читается stdin.                                       │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --system       -s      <str>    Системное сообщение.                                             │
│ --level        -l      <str>    Уровень из конфига: cheap, judge, strong…                        │
│ --model        -m      <str>    Конкретная модель 'провайдер/модель' вместо уровня.              │
│ --tag                  <str>    Метка k=v для учёта расходов; можно несколько.                   │
│ --no-cache                      Не читать и не писать кэш ответов.                               │
│ --temperature          <float>  Температура; по умолчанию из конфига.                            │
│ --max-tokens           <int>    Лимит токенов ответа.                                            │
│ --timeout              <float>  Таймаут вызова в секундах; по умолчанию из конфига.              │
│ --no-retry                      Не повторять на сбойной модели, сразу к следующей.               │
│ --template     -t      <str>    Шаблон mustache: файл, сам текст или '-' (stdin); заменяет текст │
│                                 запроса.                                                         │
│ --vars                 <str>    Переменные шаблона: JSON-файл или JSON-строка с объектом.        │
│ --lenient                       Отсутствующая переменная — пустая строка, а не ошибка (для       │
│                                 отладки).                                                        │
│ --json                          Машинный вывод: JSON-конверт в stdout.                           │
│ --help                          Show this message and exit.                                      │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
