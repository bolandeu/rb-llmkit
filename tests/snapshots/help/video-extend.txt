
 Usage: llm video extend [OPTIONS] {video}

 Поставить задание продолжения готового видео.

 Ответ — как у `llm video generate`: id задания, состояние, ссылка, модель
 и цена. Коды выхода: 0 — готово, 2 — нет routing, 3 — нет ключа шлюза,
 5 — шлюз недоступен или ответил ошибкой.

 Example: llm video extend https://video.test/1.mp4 --prompt "дальше" -m google/veo-3 --json

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    video      <str>  Ссылка на готовое видео. [required]                                       │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ *  --prompt           <str>  Что добавить дальше. [required]                                     │
│ *  --model    -m      <str>  Модель шлюза строкой как в его настройке. [required]                │
│    --routing          <str>  Routing v1: JSON или файл; иначе LLMKIT_ROUTING_FILE, иначе файл по │
│                              умолчанию.                                                          │
│    --json                    Машинный вывод: JSON-конверт в stdout.                              │
│    --help                    Show this message and exit.                                         │
