
 Usage: llm keys rm [OPTIONS] {provider}

 Удалить ключ провайдера из связки ключей.

 Удаление отсутствующего ключа не ошибка. Коды выхода: 0 — готово,
 2 — неверное имя провайдера.

 Example: llm keys rm openrouter
