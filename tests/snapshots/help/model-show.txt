
 Usage: llm model show [OPTIONS] {model_id}

 Показать одну модель шлюза по id.

 Коды выхода: 0 — готово, 2 — нет routing, 3 — нет ключа шлюза, 5 — шлюз
 недоступен, ответил ошибкой или не знает такую модель.

 Example: llm model show deepseek/deepseek-v4.1-flash-1017 --json

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    model_id      <str>  Id модели как его отдаёт `llm model list`. [required]                  │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --routing        <str>  Routing v1: JSON или файл; иначе LLMKIT_ROUTING_FILE, иначе файл по      │
│                         умолчанию.                                                               │
│ --json                  Машинный вывод: JSON-конверт в stdout.                                   │
│ --help                  Show this message and exit.                                              │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
