
 Usage: llm chat [OPTIONS] COMMAND [ARGS]...

 Прочие формы чата шлюза: responses, messages, systemone, api, модели Gemini.

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --help          Show this message and exit.                                                      │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Commands ───────────────────────────────────────────────────────────────────────────────────────╮
│ responses          Спросить шлюз формой `responses`: текст `output`, модель и цена.              │
│ responses-compact  Спросить шлюз формой `responses` со сжатием: текст, модель и цена.            │
│ messages           Спросить шлюз формой `messages` (Anthropic): текст блоков `content`, модель и │
│                    цена.                                                                         │
│ count-tokens       Сколько токенов шлюз насчитал запросу: поле `tokens`.                         │
│ systemone          Спросить шлюз формой `systemone`: текст, провайдер и цена.                    │
│ api                Спросить шлюз формой `/api/chat`: текст, провайдер и цена.                    │
│ gemini-models      Модели шлюза в форме Gemini (`name`, `displayName`) с `/v1beta/models`.       │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
