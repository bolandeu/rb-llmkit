
 Usage: llm audio speech [OPTIONS] {text}

 Озвучить текст: шлюз отдаёт байты речи, команда пишет их в `--out`.

 Ответ — путь к файлу и его content-type. Коды выхода: 0 — готово, 2 — нет
 routing, 3 — нет ключа шлюза, 5 — шлюз недоступен или ответил ошибкой.

 Example: llm audio speech "привет" -m openai/gpt-4o-mini-tts --voice alloy --out speech.mp3 --json

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    text      <str>  Что озвучить. [required]                                                   │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ *  --model    -m      <str>  Модель шлюза строкой как в его настройке. [required]                │
│ *  --out              <str>  Файл для байтов речи: шлюз отвечает не JSON. [required]             │
│    --voice            <str>  Голос шлюза; список — `llm audio voices`.                           │
│    --format           <str>  Формат ответа как его ждёт шлюз, например mp3.                      │
│    --routing          <str>  Routing v1: JSON или файл; иначе LLMKIT_ROUTING_FILE, иначе файл по │
│                              умолчанию.                                                          │
│    --json                    Машинный вывод: JSON-конверт в stdout.                              │
│    --help                    Show this message and exit.                                         │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
