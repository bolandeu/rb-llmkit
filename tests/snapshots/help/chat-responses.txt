
 Usage: llm chat responses [OPTIONS] {prompt}

 Спросить шлюз формой `responses`: текст `output`, модель и цена.

 Коды выхода: 0 — готово, 2 — нет routing, 3 — нет ключа шлюза, 5 — шлюз
 недоступен или ответил ошибкой.

 Example: llm chat responses "Столица Франции?" -m openai/gpt-5 --json

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    prompt      <str>  Текст запроса. [required]                                                │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ *  --model    -m      <str>  Модель шлюза строкой как в его настройке. [required]                │
│    --routing          <str>  Routing v1: JSON или файл; иначе LLMKIT_ROUTING_FILE, иначе файл по │
│                              умолчанию.                                                          │
│    --json                    Машинный вывод: JSON-конверт в stdout.                              │
│    --help                    Show this message and exit.                                         │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
