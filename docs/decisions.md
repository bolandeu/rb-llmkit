# Кто что решает

Карта: каждое решение llmkit — одной строкой, с тем, кто его принимает, и с единственным местом, где оно задано.
Сама причина решения — ADR ([adr/](adr/README.md)) или абзац в живом документе; поведение — код и тесты;
значения — `pyproject.toml` и `antagor.toml`.

Кто: **Код** — детерминированно, без суждения; **Настройка** — Архитектор проекта в `antagor.toml`
(защищённые — Человек, паролем); **Архитектор**, **Человек**, **Исполнитель**, **Ревьюер** — суждение.

## Продукт

| Решение | Кто | Где |
|---|---|---|
| Что llmkit делает и чего не делает; какие инструменты он обслуживает | Человек, Архитектор | `README.md`, `CONTEXT.md`, идеи |
| Взять готовую библиотеку вместо своего кода | Архитектор, Человек | ADR, `pyproject.toml` |
| Отвергнутая альтернатива, которую нельзя отменить молча | Архитектор, Человек | `docs/adr/NNNN-slug.md` |

## Публичный контракт

| Решение | Кто | Где |
|---|---|---|
| Python API (`LlmKit.ask/generate/ask_many`, `Task`, `Answer`) | Архитектор | `src/llmkit/core.py`, `src/llmkit/models.py` |
| Команды CLI, флаги, `--json`, коды выхода | Архитектор | `src/llmkit/cli/`, `src/llmkit/errors.py` (EXIT_CODES), снимки `tests/snapshots/` |
| Форма `llm describe --json` (OpenCLI), `x-rb-data`, `x-rb-env` | Архитектор | `src/llmkit/opencli.py`, `tests/snapshots/describe.json` |
| Контракты потребителей (`--json`, коды выхода, представления `v1`) | Потребитель | `tests/contracts/<потребитель>/llmkit.yaml` (копия из репо потребителя) |
| Формат routing v1 — публичная схема в колесе | Архитектор | `src/llmkit/contracts/routing-v1.schema.json` (ADR-0002) |

## Данные и база

| Решение | Кто | Где |
|---|---|---|
| **Своей базы данных нет**: ни журнала, ни кэша, ни прайса, ни миграций, ни `LLMKIT_DATABASE_URL`, ни `llm db *` | Человек | ADR-0001, §«Своей базы данных нет» |
| Расход и его группировка — из журнала шлюза (`usageHistory`, `usageDaily`), read-only; потребитель — по своему API-ключу шлюза | Код | ADR-0001, `docs/architecture.md` |
| Слой `src/llmkit/db/`, таблицы `llmkit_calls`/`llmkit_cache`, представление `llmkit_v1_calls` — код, который убирается | Исполнитель | ADR-0001 (эпик «надстройка над шлюзом») |

## Вызов модели

| Решение | Кто | Где |
|---|---|---|
| Провайдеры, уровни, цепочки и цены — данные, не код | Архитектор | ADR-0002, `src/llmkit/routing.py` |
| Классификация ошибки и порядок ретраев | Код | `src/llmkit/chain.py` |
| Цена — из ответа шлюза (`usage.cost`), `served_model` и `provider` — оттуда же; своего прайса нет | Код | ADR-0001, `docs/architecture.md` |
| Ключи: `key_env` в routing, значение — env или связка ОС; в журнал и `--json` не попадают | Код | `src/llmkit/keys.py`, `docs/architecture.md` §Ключи |
| Шлюз 9router — единственный доступ к модели; модели — строкой как в настройке шлюза | Архитектор | ADR-0001 |
| Своя цепочка ретраев, `transports/` подписок, `llm serve` — не пишем, это у шлюза | Архитектор | ADR-0001 |

## Работа в проекте

| Решение | Кто | Где |
|---|---|---|
| Форма для агентов: у каждой команды и параметра `--help` со строкой `Example:`, `--json` у всех команд, `llm doctor --json` | Архитектор | ADR-0001, `tests/snapshots/help/` |
| Режим проекта, что Архитектору можно без пароля | Человек | `mode` в `antagor.toml` |
| Проверки задачи (pytest, ruff, ty, докстринги), протокол red → green, параллельность | Архитектор | `antagor.toml`: `checks`, `[protocol]`, `parallel` |
| Гейт выпуска и деплой (`rb-release check`, `git push --follow-tags`) | Архитектор | `antagor.toml`: `[publish]`; `.gitea/workflows/ci.yml` |
| Версия и changelog — только из тега и `antagor publish` | Код | `antagor publish`, `CHANGELOG.md` |
| TDD: тест раньше кода; чужой тест меняется только при смене требования | Человек, Исполнитель, Ревьюер | `AGENTS.md`, отчёт гейта `existing tests` |
| Границы задачи, нарезка, приёмка | Архитектор | `.agents/antagor/`, скилл `antagor-slice` |
| Ревью `feature`/`bugfix` другим моделью (`pi-glm`) | Код, Настройка | `[review]` в `antagor.toml` |
| Вид каждого `.md`: живой, сгенерированный, датированная запись, данные | Архитектор | `[docs]` в `antagor.toml`, `docs/adr/`, `docs/research/` |
