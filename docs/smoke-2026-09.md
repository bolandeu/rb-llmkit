## Выводы для ядра

1. **Ollama Cloud: работает `ollama_chat/<model>` + `api_base=https://ollama.com`
   + `api_key` (Bearer).** Запасной путь `openai/<model>` + `/v1` не понадобился.
   Таблица раздела 3 SPEC верна, правок не требует.
2. `litellm.completion_cost()` для Ollama возвращает **0.0, а не исключение**.
   Значит признак «цена неизвестна» — это `cost == 0` при ненулевых токенах:
   в этом случае ядро берёт `providers.<p>.prices[model]`, а если и там пусто —
   `cost_usd=0, cost_known=False` плюс одно предупреждение на модель за процесс.
3. `gpt-oss:120b` — reasoning-модель: при `max_tokens=20` весь бюджет уходит в
   рассуждение, `content` приходит **пустым** (первый прогон так и вернул `''`).
   Пустой ответ ядро классифицирует как `invalid_output` — это корректно, но
   дефолтный `max_tokens=4096` из конфига делает ситуацию маловероятной.
4. OpenRouter отдаёт свою стоимость в `usage.cost`; `completion_cost()` даёт то же
   значение, отдельной обработки не нужно.
