# Roadmap llmkit

Что отложено за пределы v1 и в каком порядке планируется. Сделанное — в CHANGELOG.

## Ближайшее (фазы из SPEC §12)

- **Фаза 3 — перевод intentree** на llmkit: адаптер задач, метки `tool=intentree, stage, subject_type, niche`, удаление своего клиента и таблицы `llm_cache`.
- **Фаза 4 — прокси `llm serve`**: OpenAI-совместимый `/v1/chat/completions` на 127.0.0.1, метки через заголовок `X-LlmKit-Tags`, запуск как launchd-сервис.
- **Скилл для Claude Code**: вызов `llm ask/json --json` из сессий агентов для массовой обработки дешёвыми моделями.
- **Перевод antagor** (36 файлов на `generate()`), затем windmill-скрипты и одноразовые клиенты в `tasks/*`.

## Бюджеты по параметрам

Сейчас: один дневной лимит `budget.daily_usd` (20 $), только предупреждение.

План:
- **Лимиты по метке** — `[budget.tags]` с ключами вида `"tool=intentree" = 2.0`, `"niche=ved" = 1.0`: ядро уже умеет, но по умолчанию выключено и в шаблоне закомментировано. Включить, когда появится реальная потребность делить расход между инструментами и нишами.
- **Лимиты по уровню и провайдеру** — `"level=strong" = 5.0`, `"provider=openrouter" = 10.0`: та же механика, метки `level` и `provider` ядро проставляет само.
- **Периоды** — кроме дня: неделя, месяц, «на задачу» (`Task.budget_usd`, лимит на одну пачку `ask_many`).
- **Реакция на превышение** — сейчас только предупреждение (решение пользователя). Опции на будущее, по выбору в конфиге: понижение уровня на дешёвую цепочку, отказ с `BudgetExceeded`.
- **CLI** — `llm budget show/set`, а `llm cost` показывает остаток по каждому лимиту.

## Ядро

- **Негативный кэш**: стабильно падающая первая модель цепочки сейчас пробуется заново при каждом вызове. Запоминать провал на короткий срок (cooldown по модели, как в LiteLLM Router).
- **Сентинел для `default`**: сейчас `default=None` неотличим от «default не задан», вернуть осмысленный `None` нельзя.
- **Офлайн-тест пути Instructor** с настоящим `litellm.ModelResponse` и `tool_calls`.
- **Streaming** в `generate` и CLI (`--stream`), затем в прокси.
- **Embeddings**: уровень `embed`, `kit.embed(texts)` через `litellm.aembedding`, тот же учёт.
- **Батч-API провайдеров** (OpenAI Batch, Anthropic Batches) для пачек, где не важна скорость: вдвое дешевле.
- **Прогресс и возобновление пачек**: `ask_many` с чекпоинтом по `Task.id`, чтобы возобновление не зависело только от кэша.

## Инструменты

- `llm cost --export csv/json` и отчёт за период по дням.
- `llm doctor`: проверка ключей, доступности провайдеров и цен моделей одной командой.
- Цены моделей Ollama Cloud в шаблоне конфига (LiteLLM их не знает), обновление таблицы цен.
